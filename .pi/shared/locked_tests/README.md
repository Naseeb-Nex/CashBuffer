# Locked Tests

Approved, project-specific acceptance checks belong here. Treat files in this folder as immutable during implementation.

Use one file per feature: `<feature-slug>.md`.

Checks must identify whether target is:

- Next.js/React UI: component behavior, accessible output, browser state, and client/server boundary.
- Python FastAPI: route, method, request/response schema, status code, authorization, persistence, and error behavior.
